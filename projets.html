Contrôle Multimodal d'un Drone DJI Tello (Vocal, Gestuel et Manuel)

EEIA • 2026

Ce projet consiste à développer une interface de pilotage intelligente et multimodale pour le drone DJI Tello, offrant un contrôle fluide et intuitif grâce à trois modes d'interaction complémentaires : la commande vocale avec traitement des ordres en temps réel pour gérer le décollage, l'atterrissage et les déplacements de base ; la reconnaissance gestuelle basée sur la vision par ordinateur pour analyser le flux vidéo et guider le drone par des signes de la main ; et enfin une interface manuelle classique via les touches de direction pour garantir un contrôle de secours ou une précision maximale.

Outils utilisés
Python 3 VS Code djitellopy sounddevice numpy cvzone cv2

// Toggle thème sombre/clair
const toggle = document.getElementById('themeToggle');
const html = document.documentElement;

toggle.addEventListener('click', () => {
  const isLight = html.getAttribute('data-theme') === 'light';
  isLight
    ? html.removeAttribute('data-theme')
    : html.setAttribute('data-theme', 'light');
});
